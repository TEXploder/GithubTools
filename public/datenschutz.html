Bereitstellung der Website

Beim Aufruf dieser Website und der SVG-Endpunkte verarbeitet der Server technisch notwendige Zugriffsdaten. Dazu können IP-Adresse, Datum und Uhrzeit des Zugriffs, aufgerufene URL, Referrer, User-Agent und übertragene Datenmenge gehören. Die Verarbeitung ist erforderlich, um die Website auszuliefern, Fehler zu analysieren und den Betrieb abzusichern. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO.

Generator-Eingaben

Eingaben im Generator werden zur Erstellung der Vorschau und der kopierbaren SVG- oder Markdown-Links genutzt. Parameter wie Texte, Farben, Themes, Social-Link-Namen oder Timeline-Schritte können in der erzeugten URL enthalten sein und dadurch im Browser-Verlauf, in Server-Logs oder in geteilten README-Dateien sichtbar werden. Es sollten keine Passwörter, Tokens oder sonstigen vertraulichen Daten in die Generatorfelder eingetragen werden.

README Preview Sandbox

Die README Preview Sandbox rendert eingegebenes Markdown lokal im Browser. Enthält der eingegebene Inhalt externe Bilder oder Links, kann der Browser diese externen Ressourcen laden und dabei eine Verbindung zum jeweiligen Anbieter herstellen.

Externe Dienste und Links

Für Social-Icon-Vorschauen und generierte Social-Link-Markdowns können Icons von cdn.simpleicons.org geladen werden. Außerdem enthält die Website Links zu externen Seiten, insbesondere GitHub und dem Impressum unter impressum.texploder.com. Für die Datenverarbeitung auf externen Seiten sind die jeweiligen Anbieter verantwortlich.

Cookies und Tracking

Diese Website setzt keine eigenen Tracking-Cookies, verwendet keine Analytics-Funktion und bietet keine Benutzerkonten oder Newsletter an. Die Copy-Funktionen verwenden die Clipboard-API nur nach einem ausdrücklichen Klick auf die jeweilige Copy-Schaltfläche.

Speicherdauer

Technische Logdaten werden nur so lange gespeichert, wie es für Betrieb, Fehleranalyse und Sicherheit erforderlich ist. Inhalte, die du über generierte Links öffentlich teilst, bleiben dort sichtbar, wo du sie selbst einbindest oder veröffentlichst.
